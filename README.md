### 🚀 Projek

| Projek | Penerangan | Stack |
|---|---|---|
| 📖 **[Tuntutan Kelas](https://github.com/munirrr19/tuntutan-kelas)** | Guru rekod kelas Al-Quran harian, sistem jana Borang Tuntutan Mengajar setiap bulan secara automatik. | HTML · Apps Script · Sheets · PWA |
| 🕌 **e-Tasmik MTAQ** 🔒 | Rekod Tasmik, Murajaah, Tebuk Juz & Syahadah pelajar dari telefon. Jana Rekod Mingguan ikut borang sekolah. | JavaScript · Apps Script · Cloudflare Pages |
| 📱 **MTAQ Tablet Manager** 🔒 | Urus tablet sekolah: dashboard admin + Android agent, login Google melalui Cloudflare Access. | React · TypeScript · Hono · D1 · Kotlin |
| 🏫 **eSumber MTAQ** 🔒 | Sistem tempahan bilik Pusat Sumber dengan semakan tempahan bertindih (no double booking). | Cloudflare Workers · D1 |
| 🌐 **Website MTAQ** 🔒 | Website rasmi sekolah: profil, kurikulum, warga dan berita. | HTML · CSS · JS · WordPress |
| 🚗 **Carlinkit Detector** 🔒 | Kesan Android Auto melalui dongle Carlinkit pada PC / Raspberry Pi. | Python · pyusb · Java |
